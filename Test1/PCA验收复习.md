# 实验一 PCA 现场验收复习

材料依据：Test1PCA.py、TestPCAsk.py、个人实验报告和数据归约课件。原文件未修改。

## 一分钟介绍

本实验使用 Iris 数据集，共150个样本，每个样本4个特征，分别是花萼长度、花萼宽度、花瓣长度、花瓣宽度。我把4维数据降到2维，分别使用 NumPy 手动实现和 sklearn 的 PCA 实现。手动方法先对每列去均值，再计算协方差矩阵，求特征值和特征向量，按特征值降序取前两个特征向量，最后把中心化数据投影到这两个方向上。前两个主成分分别解释约92.46%和5.31%的总方差，累计约97.77%。比较时要允许特征向量整体取反；符号对齐后，两种方法的投影结果一致。

## 关键公式与形状

本代码采用样本按行排列。X 为150×4；均值向量为长度4；中心化矩阵 Xc 为150×4；协方差矩阵 C 为4×4；投影矩阵 W 为4×2；结果 Z 为150×2。

Xc = X - mean(X, axis=0)

C = Xc.T @ Xc / (150 - 1)

C v = λ v

Z = Xc @ W

第 j 个解释方差比 = λj / 所有4个特征值的和。

重建 X_hat = Z @ W.T + mean。只保留2维时一般不能精确恢复原数据。

## 代码逐句问答

- load_iris()：加载内置数据集，不需要下载文件。iris.data 是特征，iris.target 是类别。本实验不使用类别标签。
- np.mean(X, axis=0)：沿样本轴计算，每个特征得到一个均值。axis=1 则得到每个样本四个特征的均值，不符合本实验按特征中心化的要求。
- X-X_mean：利用广播，每行减去同一个长度为4的均值向量。
- np.cov(X_centered, rowvar=False)：每列代表一个变量，计算4个特征间的协方差。默认分母 n-1。np.cov 本身也会去均值，但显式 X_centered 还要用于投影。
- np.linalg.eigh(C)：用于实对称矩阵，返回实特征值和正交归一特征向量，特征向量在列中。协方差矩阵是对称矩阵，适合 eigh。
- np.argsort(eig_vals)[::-1]：获取从大到小的排序索引，不能只重排特征值，还必须对应重排特征向量的列。
- eig_vecs[:, :k]：选择前 k 列。保留所有行，不是取前 k 个样本。
- X_centered.dot(W)：矩阵乘法，不是逐元素乘法。把每个样本投影到新的主成分轴。
- PCA(n_components=2)：保留两个主成分。fit 学习均值与主成分方向，transform 按学到的方向投影，fit_transform 完成两步。
- pca.components_：每行一个主成分方向，形状2×4，与手动 W 的转置对应。
- pca.explained_variance_：主成分方差，对应协方差矩阵中选中的特征值。
- pca.explained_variance_ratio_：各主成分解释的总方差比例。
- 原代码的符号统一：将特征向量中绝对值最大元素设为正，只改变方向的正负，不改变所代表的轴。不保证所有版本的 sklearn 都采取同一约定，因此稳健比较应与实际 components_ 对齐。

## 高频原理问题

1. PCA 是什么？
无监督线性降维方法，构造互相正交的新坐标轴，优先保留投影方差最大的方向。主成分一般是原始特征的线性组合，不是直接删掉两列特征。

2. 为什么去均值？
让数据以均值为中心，使投影分析围绕数据自身的波动展开。否则直接对 X.T@X 分解会混入整体均值的影响。

3. 中心化和标准化相同吗？
不同。中心化是 x-μ；Z-score 标准化是 (x-μ)/σ。当前两份代码只中心化。sklearn PCA 默认中心化，但不自动缩放到单位方差。如果要标准化，手动和库函数必须使用相同的标准化输入重新计算。

4. 协方差矩阵表示什么？
对角元素是各特征的方差；非对角元素是两特征的共同变化程度。协方差不是相关系数，不一定在[-1,1]之间。

5. 为什么最大特征值对应第一主成分？
单位方向 w 上的投影方差是 w.T@C@w。在 w.T@w=1 的约束下，这个量的最大值是 C 的最大特征值，最优方向是对应特征向量。后续方向在与前面方向正交的约束下依次选择。

6. 为什么主成分彼此不相关？
正交归一特征向量组成 W，投影协方差 W.T@C@W 是对角矩阵，所以非对角协方差为0。不相关一般不等于统计独立。

7. 为什么选 k=2？
实验允许 Iris 取2维，便于可视化，而且累计解释约97.77%的总方差。若阈值85%或90%，1维就够；若95%，需要2维；若99%，需要3维。因此不能说任意阈值下都必须选2维。

8. “保留97.77%的信息”准确吗？
更准确是保留97.77%的总方差，不是分类准确率，不意味着保留同样比例的类别信息。

9. 手动结果和库函数符号相反，是错了吗？
不一定。若 Cv=λv，则 C(-v)=λ(-v)。反向坐标轴使对应投影坐标整列变号，但方差、距离和重建不变。应按对应主成分整列对齐符号，不能逐元素随意取绝对值掩盖错误。

10. sklearn 内部一定求协方差特征值吗？
不一定，依求解器而定，可以使用中心化数据的 SVD 等方法。若 Xc=UΣV.T，则 C=VΣ²V.T/(n-1)，因此主成分方向来自 V，特征值为奇异值平方除以 n-1。演示脚本指定 full 使用完整 SVD。

11. 为什么课件 C=XX.T/m，代码却是 X.T@X/(n-1)？
课件按列放样本，本代码按行放样本，所以转置位置和投影乘法方向不同。课件使用 m，代码使用 n-1，协方差只差一个整体常数：特征值会缩放，但主成分方向和解释方差比不变。手动结果与 sklearn 比特征值时要统一分母。

12. PCA 和 LDA 有什么区别？
PCA 不用标签，最大化投影方差；LDA 使用类别标签，寻求类内更集中、类间更分离的方向。PCA 不保证分类效果最好。

13. 新样本怎么降维？
使用训练时的均值和 W：Z_new=(X_new-mean_train)@W，或者 pca.transform(X_new)。不能给每批新数据重新 fit。分类任务中标准化与 PCA 应只在训练集拟合，避免数据泄漏。

14. 能完全恢复原数据吗？
保留少于有效秩的主成分会丢失被舍弃方向的信息；通过 Z@W.T+mean 近似重建。保留全部4个主成分可在数值误差范围内恢复本数据。

## 一个能手算的小例子

三条二维样本：(1,1)、(2,2)、(3,3)。均值(2,2)，中心化后(-1,-1)、(0,0)、(1,1)。样本协方差 C=[[1,1],[1,1]]，特征值2和0。第一特征向量为(1,1)/√2，降到1维后得到[-√2,0,√2]。所有数据都在同一条直线上，因此这次降维保留100%的方差，可以完全重建。
